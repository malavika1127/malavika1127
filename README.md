### featured projects

```
MediFusion — Integrated Healthcare Platform
  Full-stack MERN app: appointment booking, health alerts, patient reviews.
  Auth, role-based access control, Twilio-powered automated notifications.
  Modular, OOP-based architecture end to end.

TechDorm — Hostel Allocation System
  Client-server app with a normalized relational SQL schema.
  Automated allocation algorithms serving 500+ students, cutting manual
  workload by 50%.

Human Activity Recognition (HAR)
  NLP + LLM-based summarization layered on a computer-vision pipeline,
  turning video into human-readable reports. 84,000+ samples curated
  and validated. Accepted, IEEE DLCV 2026.

Video Recall Automation Pipeline — Motive
  Scalable automation pipeline generating Video Recall Requests,
  cutting manual reporting effort by 90% with runtime performance
  as a first-class constraint.

Delay-Tolerant Satellite Network Simulator
  Distributed, fault-tolerant store-and-forward routing across a
  20-satellite constellation with contact-graph-based rerouting,
  handling intermittent connectivity and orbital contact windows.
  Benchmarked under 0-30% random link/node failure injection —
  85-95% delivery success at moderate failure rates, with
  degradation analysis at higher thresholds.

FlightPulse — Cascading Flight-Delay Risk Engine
  Real-time risk engine predicting whether a flight's delay propagates
  to downstream flights on the same aircraft. Graph-based data model
  (Neo4j) for cascade path tracing, PySpark ETL, and an XGBoost model
  reaching 0.78 ROC-AUC on a time-based split. Synthetic turnaround
  simulator grounded in real BTS statistics to fill a gap no public
  dataset covers. FastAPI + WebSocket serving layer, live React dashboard.
```
